优缺点评估\n- **Orchestral**：✅ 优势：极大降低跨平台迁移成本，支持沙箱、子代理等高级功能。❌ 劣势：仅解决接口层问题，不提升 LLM 本身的推理或规划能力。\n- **GEST**：✅ 优势：物理有效性与语义对齐度显著超越纯神经生成器。❌ 劣势：依赖底层游戏引擎/模拟器，工程构建复杂，通用性受限。\n- **GeoAgent**：✅ 优势：有效处理长程、多依赖的地理空间代码任务，自我纠错能力强。❌ 劣势：MCTS+解释器+静态分析的计算开销大，实时性受限。\n- **ChemGraph-XANES**：✅ 优势：高度契合 HPC 环境，支持自然语言到高通量模拟的端到端转化。❌ 劣势：高度领域定制化，工具封装与维护成本高。\n\n---\n## 3. 性能表现评估\n### 3.1
