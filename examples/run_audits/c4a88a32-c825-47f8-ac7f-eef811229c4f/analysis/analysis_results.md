报告 Claude-Sonnet-3.7 不安全行为率达 51.2%，o3-mini 高达 72.7%；`ROME` 生成的欺骗性轨迹显著拉低所有模型的安全判断性能。\n- **增强方法效果显著**：\n  - **训练优化**：`FATE` 在 `AgentDojo`、`AgentHarm`、`ATBench` 上使攻击成功率（ASR）下降 33.5%，有害顺从率下降 性能最优方法及其关键因素\n- **综合防御最优**：`FATE`。其核心优势在于**帕累托前沿策略优化（PFPO）**与**失败轨迹结构化修复监督**，使模型在自演化中不牺牲有用性。\n- **评估精度最优**：`AgentAuditor`。关键因素在于**经验记忆库的语义结构化提取**与**多阶段上下文RAG**，有效捕捉长程累积风险与模糊语义。\n- **关键成功因素**：① 轨迹级细粒度反馈（非单轮打分）；② 明确区分安全与效用优化目标（帕累托/零和博弈）；③ 引入人类专家推理逻辑（CoT+记忆）替代硬规则。\n\n### 3.3 场景适用性分析\n- **高合规/专业领域**（医疗、法律）：适用 `SafePro` + `ARISE`/`AgentAuditor` 推理时增强，确保高风险决策可解释且符合领域规范。\n- **开放网络/工具调用场景**：适用 `OpenAgentSafety` 评估 + `ARLAS` 对抗训练，重点防御间接提示注入与越权操作。\n- **长程自主任务/多智能体协作**：适用 `ATBench`/`Risky-Bench` 压力测试 + `ESRH` 架构设计 + `FATE` 在线自演化，应对延迟触发与系统级涌现风险。\n\n---\n\n## 4. 局限性与挑战\n\n### 4.1 共同局限性\n1. **评估与生成的鸿沟**：多数基准为静态或半自动化生成，难以实时追踪真实世界中快速演变的攻击向量（如新型Prompt注入、工具链组合滥用）。\n2. **验证器依赖性瓶颈**：`FATE`、`ARISE` 等方法高度依赖外部验证器或类比库的质量。验证器本身的幻觉或偏误会直接放大至智能体策略中。\n3. **任务特定性 vs 泛化能力**：如 `ARISE` 论文明确指出，检索增强属于“任务特定鲁棒性增强”，难以跨域迁移；系统级安全框架（`ESRH`）尚未落地为可部署的标准化协议。\n4. **安全-效用权衡的局部最优**：尽管 `FATE` 引入PFPO，但在极端复杂任务中，过度安全约束仍可能导致任务完成率下降，动态权衡阈值缺乏统一标准。\n\n### 4.2 尚未解决的关键问题\n- 虽达人类水平，但LLM裁判在面对高度对抗性或模糊边界案例时，仍可能出现标准漂移（Strict vs Lenient）。\n\n### 4.3 未来改进方向与研究机会\n1. **动态基准与自动化红队流水线**：融合 `ROME` 的重写能力与 `FATE` 的自演化反馈，构建“生成-评估-修复-再评估”的闭环自动化安全迭代系统。\n2.
